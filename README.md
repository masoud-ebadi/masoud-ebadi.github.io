# Urban GIS Lab

Static HTML / CSS / JS site for the Udemy course **Urban Spatial Analysis & Modeling with ArcGIS Pro**.

Live: https://urbangispro.github.io

## Edit

- Homepage: `index.html`
- Articles: folders with `index.html`
- Styles: `assets/css/style.css`
- Course link: search for `referralCode=64855D6258A9CB243BD7`

## Deploy

Push to `main` on `urbangispro/urbangispro.github.io`.  
Settings → Pages → Deploy from a branch → `main` / root.

`.nojekyll` tells GitHub Pages to serve files as plain static files (no Jekyll build).
